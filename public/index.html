Sécurité

Votre argent est protégé à chaque étape

Les protections d'une plateforme de paiement sérieuse, pensées pour les réseaux mobiles congolais.

PIN de transaction

Chaque opération est rapprochée avec les opérateurs, et aucune n'est jamais débitée deux fois.

Questions fréquentes

Faut-il un compte bancaire pour utiliser Pay243 ?

Non. Une adresse email suffit pour ouvrir un compte, et vous le rechargez avec votre Mobile Money habituel. Une carte bancaire est possible mais pas obligatoire.

Combien coûte Pay243 ?

L'ouverture et les transferts entre wallets Pay243 sont gratuits. Un retrait vers le Mobile Money coûte 1 %. Les marchands paient 2,5 % par paiement reçu, sans abonnement.

Que se passe-t-il si le réseau coupe pendant une opération ?

Rien n'est perdu. L'opération reste « en attente » le temps que nous obtenions la confirmation de l'opérateur, et un retrait non abouti vous est intégralement restitué, frais compris.

Quels sont les plafonds ?

Les plafonds dépendent de votre niveau de vérification. Vous pouvez les augmenter à tout moment depuis l'app, en envoyant votre pièce d'identité (carte d'électeur, passeport…) et un selfie.

Je suis développeur : comment tester l'intégration ?

Créez un compte marchand pour obtenir une clé de test sk_test_…, puis suivez la documentation de l'API. Le mode test simule les opérateurs : aucun argent réel ne circule.
